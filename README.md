# NADIP / NADiSSP-Corpus

**Nigerian-Adapted Domain-Invariant Prognostic (NADIP) Framework**

Transfer Learning + Domain Adaptation for Predictive Maintenance on Heterogeneous Oil & Gas Assets

## Overview

NADIP is a hybrid transfer-learning and domain-adaptation framework designed for predictive maintenance (PdM) across heterogeneous oil-and-gas assets under Nigerian operating conditions.

It combines:

- Transformer backbone with Gradient Reversal Layer (GRL) adversarial domain adaptation
- SimCLR self-supervised contrastive learning
- RUL + failure heads
- SHAP / permutation explainability
- Monte-Carlo TCO/NPV economic evaluation

**Key empirical results (Nigerian-augmented + real 3W facility evaluation):**

| Metric | Source-only | Full NADIP | Improvement |
|--------|-------------|------------|-------------|
| Composite MMD | 0.82 | 0.26 | -68.3% |
| AUPRC (rare-fault detection) | 0.54 | 0.85 | +57% |
| RUL RMSE (cycles) | 21.64 | 12.74 | -41% |
| 5-year NPV per refinery | - | ~$892 M | - |
| Latency (RPi 5 8 GB) | - | <120 ms | - |

**Real facility data:** The framework is evaluated on the **Petrobras 3W Dataset 2.0.0** — real offshore oil-well telemetry containing rare undesirable events. This is the primary real-facility target domain used in the dissertation.

## Quick Start

```bash
git clone https://github.com/EkeminiThompson/NADiSSP-Corpus.git
cd NADiSSP-Corpus
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

python scripts/download_datasets.py
python scripts/prepare_corpus.py
python scripts/train_nadip.py --epochs 40
python scripts/evaluate.py --checkpoint checkpoints/nadip_full.pt
python scripts/run_ablation.py --epochs 15
python scripts/run_economic.py
python scripts/generate_figures.py
```

## Key Design Decisions

- **3W is the real facility target domain** (not merely another benchmark).
- Nigerian stressors via physics-informed augmentation (humidity, corrosion, sabotage, telemetry dropout, sampling mismatch, wave loading).
- Ablation isolates GRL, SimCLR, multi-dataset diversity.
- Economic evaluation uses Monte-Carlo TCO/NPV with Nigerian cost parameters.
